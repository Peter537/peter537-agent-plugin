# Support

Support for Peter537 Agent Plugin is provided through [GitHub Issues](https://github.com/Peter537/peter537-agent-plugin/issues) on a best-effort basis.

## Before opening an issue

Check the current [README](README.md), confirm which edition you installed, and reproduce the problem with the latest applicable release before reporting it.

## What to include

- Plugin version and installation source.
- Client and client version, such as ChatGPT/Codex desktop, Codex CLI, or another Agent Plugins client.
- Operating system and the relevant Node.js, `uv`, or Python version when an MCP server is involved.
- Clear reproduction steps, expected behavior, and actual behavior.
- Minimal redacted logs or a minimal public example when they materially help reproduce the problem.

## Protect sensitive information

Do not include credentials, tokens, private repository content, personal data, private package coordinates, internal registry URLs, or other sensitive information in an issue. Redact logs before attaching them.

Do not publicly disclose an unpatched vulnerability. If GitHub private vulnerability reporting is available for this repository, use it. Otherwise, open an issue containing only a request for a private reporting channel and no vulnerability details.

## Third-party services

Questions about service availability, accounts, data handling, or service-specific behavior may need to be handled by the relevant third-party provider. Reports about this plugin's manifests, skills, documentation, or integration configuration belong in this repository.
