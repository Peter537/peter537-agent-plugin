# Independent shift tasks

These three cards group independent jobs, each with its own checklist. Operators choose by task rather than compare aligned record fields. The conventional grouping, restrained borders and neutral colors are intentional. There is no workflow ordering or business state to invent.

Review the interface and apply only a correction supported by a concrete user consequence. An unchanged result is appropriate when no warranted correction is found. Only `index.html` and `styles.css` are authorized; preserve all supplied content, native disclosure behavior and test hooks. No arbitrary novelty, pattern ban or spacing target is required.

Start in this directory with `python -B -m http.server 8000 --bind 127.0.0.1`, replacing an occupied port. Inspect `index.html` at 1280 by 720 and 375 by 812, including keyboard disclosure and focus. Stop the owned server afterward. No external resources or installation are required. Preserve Git staging and unrelated files; report in conversation.
