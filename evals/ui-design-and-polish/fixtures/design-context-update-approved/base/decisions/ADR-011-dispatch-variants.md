# Dispatch variants

The web console uses compact rows for comparison. The tablet variant uses larger touch targets and a single expanded route at a time. Both variants preserve route order, assignment confirmation, and text-plus-icon risk labels.

The amber route-risk rail remains approved only for the route comparison column. No decision authorises amber as a global brand colour.
