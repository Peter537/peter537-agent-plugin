# Cold-chain exception review

Warehouse quality operators decide whether a temperature excursion can be released, held, or quarantined without losing the evidence behind the decision.

The interface must preserve evidence order, keep the shipment identifier visible, expose populated, empty, loading, permission-denied, and stale-data states, and require confirmation before quarantine. Danish operator copy is an approved supported locale. The default desktop density remains undecided.

The council approves `docs/product-design-context.md` as the authoritative persistent design-context path for this scope.
