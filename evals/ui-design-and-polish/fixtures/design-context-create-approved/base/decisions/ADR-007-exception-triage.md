# Exception triage decisions

- Evidence remains in chronological order.
- Release, hold, and quarantine are the supported outcomes.
- Quarantine is destructive and requires explicit confirmation.
- Colour never carries status meaning by itself.
- A narrow teal evidence rail is allowed only beside chronological sensor evidence.

The rail is a scoped product marker, not a general decoration, global brand colour, or replacement token system. Desktop density remains an open product decision.
