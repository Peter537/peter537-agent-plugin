# Dispatch variants

The web console uses compact comparison rows. The tablet variant uses larger touch targets and a single expanded route at a time. Both variants preserve route order, assignment confirmation, and text-plus-icon risk labels.

A narrow amber rail may anchor risk evidence only in the route comparison column so operators can scan rows without losing the evidence relationship. Amber is not a global brand colour.
