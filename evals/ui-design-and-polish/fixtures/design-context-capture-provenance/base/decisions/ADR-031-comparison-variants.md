# Comparison variants

Desktop uses compact ordered comparison rows so operators can compare route risks. Tablet keeps larger touch targets and one expanded route at a time. Risk labels include text and an icon; colour alone is insufficient.

This decision supersedes the comfortable desktop prototype and colour-only risk indicators documented in CAP-012. The narrower amber evidence rail remains allowed only in the desktop comparison column, where it connects risk evidence to its route. It is not global product branding.

Exact responsive breakpoints and motion remain unresolved. An observed transition in a capture is not a motion decision.
